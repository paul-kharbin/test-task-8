# Candidate Tracker

Тестовое приложение: API на ASP.NET Core, SPA-клиент на React, БД MSSQL.

Используется Code First.

SPA-клиент находится в `TestTask.Web.Front`.

## Запуск

Из корня солюшена

```sh
./publish-react-and-run.ps1
```
Перейти в брайзере на `http://localhost:5000`

или

Открыть союшен. F5, потом в `TestTask.Web.Front` выполнить

```sh
npm install
npm run dev
```
Перейти в браузере на `http://localhost:5173`
